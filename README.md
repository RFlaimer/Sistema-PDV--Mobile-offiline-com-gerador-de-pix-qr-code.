# Sistema-PDV--Mobile-offiline-com-gerador-de-pix-qr-code.
Sistema PDV simples e otimizado para celular para cadastrar produtos, marcas, quantidades e preços, montar pedidos e gerar comprovantes em PDF ou impressora térmica com Pix Copia e Cola e QR Code. Também permite consultar o histórico e exportar backups dos pedidos.
